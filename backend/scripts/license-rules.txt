# License rules for the Python environment (read by check-licenses.sh).
#
# Line format, fields separated by "|":
#   allow  | <license>
#   except | <package> | <license> | <reason> | <decision record>
#
# "allow" lists one accepted spelling per line. A license string reported by
# pip-licenses must equal an entry exactly (case-sensitive). There are no
# wildcards: a new spelling fails the check until it is added here on purpose.
# Expressions are evaluated: "A OR B" passes if one side is allowed,
# "A AND B" only if every side is allowed.
#
# "except" accepts one named package with exactly the stated license. Anything
# that is not on the preferred list of guardrail 7 or its equivalents goes
# here, never under "allow". UNKNOWN can never be allowed in general; a
# package without a detectable license needs its own "except" line after it
# has been clarified.
#
# Decision records live in docs/DECISIONS.md.
