# License rules for the npm packages (read by check-licenses.sh).
#
# Line format, fields separated by "|":
#   allow      | <license>
#   allow-dev  | <license>
#   except     | <package> | <license> | <reason> | <decision record>
#   except-dev | <package> | <license> | <reason> | <decision record>
#
# "allow" lists one accepted spelling per line. A license string reported by
# license-checker-rseidelsohn must equal an entry exactly (case-sensitive).
# There are no wildcards: a new spelling fails the check until it is added
# here on purpose. Expressions are evaluated: "A OR B" passes if one side is
# allowed, "A AND B" only if every side is allowed.
#
# "allow-dev" is valid only for packages outside the production tree
# (everything that "npm ci --omit=dev" would not install). Such packages are
# development and build tools and never reach the shipped files.
#
# "except" accepts one named package with exactly the stated license;
# "except-dev" does the same, but only outside the production tree. Anything
# that is not on the preferred list of guardrail 7 or its equivalents goes
# here, never under "allow". UNKNOWN and UNLICENSED can never be allowed in
# general; such a package needs its own exception line after it has been
# clarified.
#
# Decision records live in docs/DECISIONS.md.
