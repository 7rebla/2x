**Betreff:** Frage zur Lizenz der GitHub-Repositories zur Agile Production Simulation 24V

Guten Tag,

ich arbeite privat an einem quelloffenen Softwareprojekt, das technische Unterlagen und Konfigurationen von Fertigungsanlagen einliest und durchsuchbar macht. Zum Testen möchte ich die Agile Production Simulation 24V (Art.-Nr. 569289) als Beispielanlage verwenden, weil Ihre Unterlagen und Programme öffentlich abrufbar und sehr gut dokumentiert sind.

Dabei geht es um diese Quellen:

1. https://github.com/fischertechnik/Agile-Production-Simulation-24V
2. https://github.com/fischertechnik/Agile-Production-Simulation-24V-Dev
3. die Dokumente der Seite „Agile Production Simulation“ unter „Technische Dokumente“ auf fischertechnik.de

Bei der Durchsicht ist mir aufgefallen, dass beide Repositories keine Lizenzdatei enthalten. Das README des zweiten Repositorys verweist im Abschnitt „License“ auf eine LICENSE-Datei, die es dort nicht gibt; die Paketbeschreibung der Zentralsteuerung trägt die Angabe „UNLICENSED“.

Daraus ergeben sich zwei Fragen:

1. Ist für die beiden Repositories eine Lizenz geplant? Wenn ja: welche, und ab wann?
2. Ist die folgende Nutzung aus Ihrer Sicht in Ordnung?
   - Mein Projekt veröffentlicht ausschließlich ein Abruf-Skript mit den Adressen Ihrer Dateien, den festgelegten Commit-Ständen und Prüfsummen.
   - Wer das Projekt testet, lädt die Dateien damit selbst von Ihren Servern und von GitHub auf den eigenen Rechner.
   - Ich gebe keine Ihrer Dateien weiter – weder im Repository noch auf anderem Weg – und übernehme keine längeren Textauszüge. In der Projektdokumentation stehen nur die Quellenangaben und eigene Beschreibungen.
   - Die Dateien werden nur gelesen. Es wird nichts verändert und nichts auf eine Anlage zurückgeschrieben.

Falls Sie eine bestimmte Form der Quellenangabe wünschen oder einzelne Dateien ausgenommen sehen möchten, richte ich mich gerne danach. Das gilt auch für das im README verlinkte Raspberry-Pi-Abbild; ich führe es derzeit nur als Verweis und lade es nicht.

Vielen Dank für Ihre Mühe und für eine kurze Rückmeldung.
